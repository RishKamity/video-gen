# NIST CSRC Glossary: collision and collision resistance

- URLs: https://csrc.nist.gov/glossary/term/collision and https://csrc.nist.gov/glossary/term/collision_resistance
- Publisher: NIST Computer Security Resource Center
- Retrieved: 2026-11-14

Exact excerpts read through a web-fetch tool (the build machine could not download csrc.nist.gov directly).

## collision

- NIST SP 800-106 and SP 800-107 Rev. 1: "An event in which two different messages have the same message digest."
- NIST SP 800-38B and NIST IR 8459: "For a given function, a pair of distinct input values that yield the same output value."
- NIST SP 800-57 Part 1 Rev. 5: "Two or more distinct inputs produce the same output. Also see hash function."

## collision resistance

- NIST SP 800-107 Rev. 1: "An expected property of a hash function whereby it is computationally infeasible to find a collision, See "Collision"."
