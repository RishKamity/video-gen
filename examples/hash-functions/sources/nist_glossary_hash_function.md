## Excerpts

- NIST SP 800-107 Rev. 1, "Hash function": "A function that maps a bit string of arbitrary length to a fixed-length bit string."
- NIST SP 800-152, "Hash function": "A hash function can be considered to be a fingerprint of the file or message."
- NIST SP 800-185, "Hash Function": "The output often serves as a condensed representation of the input."
- FIPS 186-5, "Hash function": "A function on bit strings in which the length of the output is fixed."

Summary from the same page (paraphrase, not a quote): most entries say approved hash functions are expected to be one-way (preimage resistant) and collision resistant; SP 800-107 Rev. 1 also lists second-preimage resistance.
