## preimage resistance

- NIST SP 800-107 Rev. 1: "An expected property of a hash function such that, given a randomly chosen message digest, message_digest, it is computationally infeasible to find a preimage of the message_digest, See "Preimage"."
- NIST SP 800-106 gives the same definition for "a cryptographic hash function".
